# json-formatter-and-validator

A JSON formatter and validator built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a modern browser.
No installation, server, or internet connection is required.

## Features

- Validate JSON and display success or error feedback.
- Format valid JSON using four-space indentation.
- Show a helpful message for empty or whitespace-only input.
- Clear the input and feedback.

All processing happens in your browser.
Pasted JSON is not sent anywhere.
